01 — Simulation

Kestrel Studio

A physics-based environment for modelling how a signal actually travels. Terrain, weather, platform motion, antenna patterns, and interference all resolve in one solver so a result is defensible rather than indicative.

  • GPU ray-tracing with UTD diffraction and rough-surface scattering
  • ITU-R P.676/P.838 atmospheric and rain models; 3GPP TR 38.901 statistical channels
  • Imported antenna patterns from HFSS, CST, FEKO, or measured cuts
  • Phased-array synthesis including mutual coupling and element failure studies
  • Monte-Carlo campaigns distributed across a cluster, resumable mid-run

03 — Hardware in the loop

Kestrel Range

Real-time RF environment generation. Take a Studio scenario and play it into a live receiver at full rate — dynamic delay, Doppler, angle of arrival, and pulse-dense emitter traffic, all deterministic enough to repeat a failure exactly.

Dense emitter scenes

Above 4.1 M pulses/second across 64 simultaneous emitter tracks, with agile PRI, frequency hopping, and realistic scan patterns.

2 GHz per channel

Instantaneous bandwidth to 2 GHz on supported RFSoC and PXIe targets, with phase-coherent multi-channel arrays.

Deterministic timing

Sub-microsecond scenario latency, disciplined to IEEE 1588 or a GPSDO, so a captured anomaly replays on the same sample.

04 — Developer platform

Kestrel Core SDK

Every capability in the platform is a library call first and a UI second. Core is what Studio, Bench, and Range are built on — and it ships with the same support contract.

  • Python 3.10+, C++20, and a MATLAB toolbox against one ABI
  • Zero-copy NumPy I/Q buffers; Arrow and pandas result frames
  • SigMF, HDF5, and Touchstone readers and writers
  • Deterministic seeding — a run from three years ago reproduces bit-identical
  • Redistributable runtime for embedding in your own tooling
quickstart.py 
import numpy as np
from kestrel.core import IQ, channel, metrics

tx = IQ.from_sigmf("captures/nr_ul_64qam.sigmf")

ch = channel.TappedDelayLine(
    taps_ns=[0, 31, 72, 190],
    gains_db=[0, -3.2, -7.9, -14.1],
    doppler_hz=210,
    seed=1337,
)

rx = ch(tx) + IQ.awgn(snr_db=14, seed=1337)

print(metrics.evm(rx, reference=tx))   # 2.71 %
print(metrics.aclr(rx, bw=100e6))       # 33.8 dB

np.save("rx.npy", rx.asarray())     # zero-copy
