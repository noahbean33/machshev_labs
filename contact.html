Before you ask

Questions we get every week

Will it drive the instruments I already own?

Almost certainly — 400+ validated drivers cover the major SCPI, IVI, and VISA families. If yours is missing, we write it, typically within two weeks and at no charge on Program tier and above.

Can it run fully offline?

Yes. Air-gapped installation with an offline license server is a supported configuration, with signed update bundles delivered on media. Nothing phones home.

How accurate is the solver, really?

Every release ships a validation report against reference range measurements, including the cases where we disagree and by how much. Ask for the current one — we send it before a purchase, not after.

What does onboarding look like?

Two days of remote pairing with an applications engineer, working on one of your real test cases rather than a toy. Most teams have a suite running in CI inside the first fortnight.
